# Linux Command Line Forensics Basics (Lab 2A)

## Overview

This repository contains my submission for **CIP-B101 Lab 2A: Linux Command Line for Digital Forensics Basics**.

The project demonstrates practical Linux skills commonly used in Digital Forensics and Incident Response (DFIR), including filesystem investigation, inode analysis, evidence searching, shell scripting, network inspection, and evidence preservation.
