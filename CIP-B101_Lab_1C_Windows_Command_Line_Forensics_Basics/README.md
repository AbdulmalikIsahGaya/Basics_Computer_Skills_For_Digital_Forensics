# Windows Command Line Forensics Basics

## Overview
This repository contains lab work completed as part of the **CIP-B101 Basic Computer Skills for Digital Forensics** course.

The lab demonstrates foundational Windows command-line techniques used in digital forensics investigations, evidence collection, system triage, and incident response.

## Learning Objectives
- Understand Windows file system navigation.
- Work with absolute and relative paths.
- Create and manage evidence files.
- Collect system and network information.
- Search for evidence using command-line tools.
- Review file ownership and permissions.
- Enumerate system processes.
- Automate forensic tasks using batch scripts.

## Lab Activities
### Evidence Preparation
- Created a structured forensic workspace.
- Organized evidence, outputs, screenshots, and scripts.

### File System Navigation
- Used `cd`, `dir`, and path navigation techniques.

### File Operations
- Created, copied, renamed, and deleted files.
- Practiced output redirection using `>` and `>>`.

### System Enumeration
- Gathered host, CPU, memory, BIOS, and storage information.

### Network Enumeration
- Collected IP configuration data.
- Identified MAC addresses.
- Tested connectivity using `ping`.

### Evidence Searching
- Used `findstr` to locate forensic indicators.

### Process Analysis
- Enumerated running processes.
- Investigated browser-related processes.

### Scripting and Automation
- Developed basic batch scripts.
- Generated automated forensic reports.
